# Blog notes

This folder contains longer narrative writeups about the project: why a skill exists, what problem it solves, how it was built, and what was learned while testing it.

These are human-facing notes, not installable skill files. They should be readable from GitHub without local context.

## Files

- [`building-the-dataviz-selector-skill.md`](building-the-dataviz-selector-skill.md) - narrative note on why the selector skill exists and how it was built.

## Edit rule

Keep these posts concrete. Start from the project context, explain the tradeoffs, and avoid release-note prose. If a writeup refers to a skill that has changed materially, update the post or add a note rather than pretending the old behaviour is current.
