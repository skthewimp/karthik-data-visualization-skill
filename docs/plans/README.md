# Plans

Planning docs for future skill builds and multi-session work. These files are not authoritative skill instructions; they are project-management notes that explain what might be built next and why.

## Files

- [`agentic-dataviz-skill-build-plan.md`](agentic-dataviz-skill-build-plan.md) - build plan for the next wave of agentic dataviz skills, now updated to account for the dataset-question generator, contextual data-cleaning skill, and orchestrator.
- [`dataviz-repair-product-roadmap.md`](dataviz-repair-product-roadmap.md) - TODOs for bounded repair loops, versioned audience and purpose context, and a bring-your-own-key tester web app.
- [`staged-pipeline-contract.md`](staged-pipeline-contract.md) - the staged, per-stage-bundled contract that replaced the single mega-prompt, and the remaining tester conversion.
- [`weak-model-repair-hardening.md`](weak-model-repair-hardening.md) - plan to make the repair pipeline hold up on cheaper/open-weight models by moving orchestration and mechanism out of prose into runtime validators and the MCP server, leaving only judgment in the text skills.

## Edit rule

When a planned skill gets built or superseded, update the status board and the dependency notes. Do not let this folder keep advertising stale “next skill” plans after the repo has moved on.
